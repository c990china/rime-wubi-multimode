【新电脑复现 · 配置替换说明】

【素材分工】
  安装包 + 上游配置包（zip）→ 自行准备（下载地址见 QUICKSTART.md）
  方案文件 + 词库 + 脚本 → 本仓库根目录

1. 装好小狼毫 Weasel（用户目录保持默认 %AppData%\Rime）。

2. 解压 rime-wubi86-jidian-master.zip，把里面所有 yaml 等文件复制到 %AppData%\Rime
   （⚠️ zip 内有顶层目录 rime-wubi86-jidian-master\，注意把里面的文件取出放进
   %AppData%\Rime\，别整个目录塞入，否则 Rime 读不到）

3. 用本仓库 config\ 下的文件覆盖到 %AppData%\Rime：
     wubi86_jidian.schema.yaml      （主方案：z 引导拼音 + 四码顶字上屏）
     default.custom.yaml            （方案列表：只启用 wubi86_jidian）
     weasel.custom.yaml             （外观）

4. 【必须做】建立软链接，否则词库与候选词屏蔽、英文回显都不生效：
   以管理员身份运行
     <本仓库根目录>\dict\setup-symlinks.cmd
   它会建三条软链接（词库 + lua 候选屏蔽 + lua 英文回显），并自动核对结果。
   ⚠️ 先建 lua 链接再部署，否则输入法一个字都打不出。

5. 右键任务栏右下角小狼毫托盘图标 → 重新部署

完整步骤、自检清单与排障见本仓库：
  README.md
